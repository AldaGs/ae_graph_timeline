# M3 — Live Reconciler & Node Compositing

**Status: CORE DONE; PANEL INTEGRATION REPAIRED, MANUAL VERIFICATION OPEN**

M3 adds the live graph-to-After-Effects write loop and standalone effect and
expression nodes. The core model/diff/patch/loop path is implemented and covered
offline. A 2026-09-14 review found panel-level wiring defects that are outside
the current test suite, so the milestone should not be treated as end-to-end
complete until those are fixed and exercised in AE.

## Decisions (locked)

| question | decision | rationale |
|---|---|---|
| Effect Nodes | **Standalone nodes** | Match true compositing workflows (Nuke/Fusion). |
| Effect Flattening | **Trace flow edges to build layer stack** | AE requires effects on layers. We flatten the visual chain (Source -> Blur) into a single AE layer for MVP. Null-hosted shared effects follow for branching. |
| Expressions | **Expression Node (String Type)** | Users write code in a dedicated node and wire it to a property, copying the string directly to AE. No `eval()` speed costs. |
| Adding Nodes | **Right-Click Context Menu** | Cleaner UX than a toolbar palette. |
| Compositions | **Track `compName`/`compId`** | The graph needs to know which AE comp it represents to support jumping between comps later. |
| Null-Host Sharing | **Effects on Null layers + relative property links** | When an effect node is shared (wired to multiple sources), a Null layer hosts the effect and consumers link via `thisComp.layer("Host").effect(1)(i)` expressions. Non-graph users see normal expressions — no breakage. |
