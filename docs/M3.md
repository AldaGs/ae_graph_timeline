# M3 — Live Reconciler & Node Compositing

**Status: IN PROGRESS**

M3 wires the React canvas directly to After Effects, establishing the live two-way sync loop. It also introduces a major architectural shift: moving from a layer-centric model to a true node-based compositing model where effects are standalone nodes that chain together.

## Decisions (locked)

| question | decision | rationale |
|---|---|---|
| Effect Nodes | **Standalone nodes** | Match true compositing workflows (Nuke/Fusion). |
| Effect Flattening | **Trace flow edges to build layer stack** | AE requires effects on layers. We flatten the visual chain (Source -> Blur) into a single AE layer for MVP. Null-hosted shared effects will follow when branching is tackled. |
| Expressions | **Expression Node (String Type)** | Users write code in a dedicated node and wire it to a property, copying the string directly to AE. No `eval()` speed costs. |
| Adding Nodes | **Right-Click Context Menu** | Cleaner UX than a toolbar palette. |
| Compositions | **Track `compName`/`compId`** | The graph needs to know which AE comp it represents to support jumping between comps later. |
