### R1 · P1 · Label and blend edits silently disappear at the reader boundary — FIXED (M4.8)

`jsx/reader.jsx` builds layer records without label/blendMode; `src/reader.js`
also omits them. `src/diff.js` only emits these writes when the observed fields
are defined. Consequently the inspector can change the graph and report a clean
diff while AE retains the old value. Recovery/capture also cannot recover them.

Reproduced against `makeAE`: host layer label 4 / MULTIPLY, graph label 2 / screen.
After `parseCompState(ae.eval(readCompCall()))`, both fields are undefined and
`diff(graph, state).ops` is empty. This is an existing integration gap, not a
passing end-to-end feature despite the individual blend writer tests.

Fix: serialize and normalize both fields, share the supported blend mapping,
handle unsupported layer kinds explicitly, and test command → real JSX read →
diff → patch → read convergence and AE-side change detection. Add label to drift
facts/comparison as well. Keep unknown host enums explicit rather than guessing.

### R2 · P1 · Duplicate cleanup leaves stale tag counts within the patch — FIXED (M4.8)

`ntlpSetComment` in `jsx/patch.jsx` changes the host comment without updating the
patch context's tag representative/count. A following operation on the surviving
original still sees two claimants and fails after the cleanup has already landed.

Reproduced against `makeAE`: two layers tagged `ntl:a`; one patch strips the
copy's comment using its native ID, then renames `a`. It fails at op 1 with
`2 layers carry the tag "a"; refusing to guess`, returning a partial receipt.

Fix: maintain tag membership when comments change (including rollback retags),
or apply a verified batch reindex before dependent writes. Test duplicate cleanup
plus rename, properties, reorder and inverse application in the same patch.

### R3 · P2 · Interactive/host acceptance is absent

The automated suite does not exercise React focus, hook cleanup, native dialogs,
DOM paint or real host behavior. Performance results are Node/fake-host only.
The minimap threshold is provisional. Run the matrix in PERFORMANCE.md before
accepting M4.7's scale gate. M4.6's remaining workflows are still outstanding.
