# M4 — Durable Identity

**Status: PLANNING**

M4 makes the graph survive real-world After Effects workflows: save/reopen,
duplicate layers, and precompose. Today the identity system has all the pieces
(S3's comment tag + native ID hybrid), but they are not wired end-to-end in
production code.

---

## The Problem

Six gaps discovered during the M3 review:

| # | gap | impact |
|---|---|---|
| 1 | `graph.nodes[nodeId].nativeId` is **never set** in production | duplicate disambiguation always falls back to `layers[0]` — a coin flip |
| 2 | `ntlpLayer` in `patch.jsx` **throws unconditionally** when `counts[nodeId] > 1` | after a user Cmd+D, **every patch fails forever** until the comment is hand-edited |
| 3 | No op exists to **clear or change a comment** on a layer | the duplicate can't be disambiguated by the reconciler |
| 4 | `ntlpDeleteLayer` **ignores `op.nativeId`** | can't delete a specific duplicate |
| 5 | Precompose changes `nativeId` but keeps the tag — the guard flags `replaced` and **blocks forever** | no way to re-bind the handle |
| 6 | `seedGraph()` is hardcoded — **reopening a project deletes all managed layers** | catastrophic data loss on panel reload |

---

## Decisions (to lock with user)

| question | proposed decision | rationale |
|---|---|---|
| Duplicate handling | **Original keeps tag; copy is stripped** (`comment = ''`) and becomes unmanaged | The graph owns exactly one layer per node. A copy is the user's. |
| Precompose re-bind | **Accept the new nativeId** when the tag is intact and unique | The comment survived; only the handle changed. Update the cache, don't block. |
| Panel reload | **Hydrate from comp** — scan tagged layers and rebuild graph nodes, don't use `seedGraph()` | Prevents the deletion catastrophe. M6 (persistence) will add `.ntl` file loading. |
| Native ID in ops | **Ops carry `nativeId` alongside `node`** when disambiguation is needed | ExtendScript can resolve by `layer.id` when a tag scan is ambiguous. |

## Checklist

### Phase A — Native ID lifecycle

- [ ] `src/graph.js` — `addNode` preserves `nativeId` if passed. Add `bindNativeId(graph, nodeId, nativeId)`.
- [ ] `jsx/patch.jsx` — `ntlpCreateLayer` returns `{ node, nativeId: layer.id }` in the receipt.
- [ ] `src/patch.js` — `parseReceipt` extracts `created` map of `{ node → nativeId }`.
- [ ] `src/loop.js` — after a successful patch, bind `nativeId` from receipt onto `graph.nodes`.
- [ ] `test/patch.test.js` — verify receipt carries native IDs for created layers.

### Phase B — Duplicate disambiguation

- [ ] `jsx/patch.jsx` — new op `setComment`: writes `layer.comment` on a layer resolved by `nativeId`.
- [ ] `jsx/patch.jsx` — `ntlpLayer` gains a fallback: when `counts > 1` and `op.nativeId` is present, resolve by `layer.id` scan instead of throwing.
- [ ] `src/diff.js` — when a duplicate is detected, emit `setComment` op to strip the copy's tag (`comment = ''`).
- [ ] `src/diff.js` — `deleteLayer` carries `nativeId`; `ntlpDeleteLayer` uses it when tag is ambiguous.
- [ ] `src/patch.js` — `setComment` in `SUPPORTED_OPS`.
- [ ] `test/diff.test.js` — duplicate detected → original kept, copy stripped.
- [ ] `test/patch.test.js` — `setComment` op tested in VM.

### Phase C — Precompose re-bind

- [ ] `src/drift.js` — `replaced` drift: when the tag is intact and unique, downgrade from `BLOCKING` to `rebindable`. Emit a re-bind event instead of refusing.
- [ ] `src/loop.js` — on `rebindable` drift, auto-update `graph.nodes[nodeId].nativeId` and continue.
- [ ] `test/drift.test.js` — precompose scenario: nativeId changes, tag survives, loop re-binds silently.

### Phase D — Comp hydration (panel reload safety)

- [ ] `src/graph.js` — `hydrateFromComp(graph, compState)`: for each managed layer in compState, if node exists update `nativeId`, if not create a minimal node.
- [ ] `panel/src/App.jsx` — on startup, read the active comp and hydrate instead of using `seedGraph()`.
- [ ] Guard: if graph is empty and comp has managed layers, hydrate. If graph has nodes and comp has matching tags, bind native IDs. If graph has nodes with no comp match, flag for user decision.
- [ ] `test/diff.test.js` — hydrated graph diffs clean against its source comp.

### Phase E — Verification

- [ ] `npm test` — all green.
- [ ] `npm run build` — panel builds.
- [ ] Manual AE test: create layers → close panel → reopen → layers survive.
- [ ] Manual AE test: duplicate a managed layer → duplicate becomes unmanaged, original untouched.
- [ ] Manual AE test: precompose a managed layer → graph re-binds, no blocking drift.
