# M2 — Node Set

**Status: DONE**

M2 gives the graph enough vocabulary to build a simple shot. After M1 proved the
canvas over the model, M2 widens what a node can be and what it can carry.

---

## Decisions (locked)

| question | decision | rationale |
|---|---|---|
| Effect scope | **generic, by matchName** | the reader already reads all effects; a generic `setEffect` avoids hand-coding each one |
| Layer kinds | **all AE kinds supported**; shape and footage imported from comp rather than created from scratch | creating a shape from nothing is not useful; importing one the user already built is |
| Effect ordering | **ordered array**, stacked in order of connection | AE effects are order-dependent; the array models that naturally |
| Composite node | **blend mode** on a layer | compositing in AE is implicit in the stack; the node surfaces it as a field |
| Node colours | **AE system label colours** distinguish layer types on the canvas | keeps the visual language familiar to AE users |
| Unmanaged layers | the graph inspects the current comp, counts unmanaged layers, and **offers to import them** | discovered during M2 planning; belongs to M3's read path |
