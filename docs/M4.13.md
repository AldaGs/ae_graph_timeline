## Why this is the next phase

M4.8 through M4.12 repaired the defects found in live use and filled several
visible editing gaps. Every one of those slices deliberately stopped at the
same boundary: its behavior is covered offline, but not accepted in a real CEP
panel against After Effects.

That debt is now one phase rather than five separate footnotes. M4.13 does not
add product surface. It proves that the surface already present is safe,
coherent, and durable in the host. A failure belongs to this phase even when the
fix lands in code first introduced by an earlier milestone.

The gate is intentionally stricter than “the panel opened.” Each scenario must
record the expected writes, the writes actually observed, the number of After
Effects undo entries, and the state after undo and redo. A visual result without
that evidence is a smoke test, not acceptance.

## First live-run findings and fix pass

The first run found four symptoms with three shared causes.

1. **Comp switching stopped deliberately.** The identity watcher closed the old
   comp's write loop correctly, but then presented **Inspect Active Comp**. It
   now scans the new active comp automatically after the old comp-id-guarded
   lane is closed. A React hook test covers both automatic switching and the
   separate missing-comp read-only path.
2. **Undo history was committed too early.** The panel stored the graph at the
   `patched` event, before AE's checkpoint supplied created native ids,
   host-defaulted transforms, and the real post-patch comp state. Those guessed
   states could not match a later AE undo or redo. History now stores the AE
   observations on both sides and commits only at `checkpoint`; creation,
   deletion, property undo, redo, and multi-undo matching are covered offline.
3. **A shared Fill looked perpetually unlinked.** The live sidecar reproduced
   two permanent `linkEffectToHost` operations. AE exposes menu/topic parameters
   that cannot accept expressions, while the diff required an expression on
   every reported value. The reader now reports the exact expression-capable
   parameter set and the diff judges only that set. Capture and reopen converge
   to zero operations with the live-run graph shape.

The persisted graph also carried M4.8-era host-null transforms in an effect
node's parameter bag. Reopen now removes keys that are not present on the real
effect. This is covered as an explicit persistence repair rather than requiring
the tester to delete the sidecar by hand.

The first disposable project was exercised through failed undo/redo and contains
a real graph/comp kind mismatch caused during those failures. Keep it as evidence;
use a fresh disposable project for the fix verification run.

## Acceptance matrix

### A · Opening is read-only

- [ ] Open the panel with no active comp: only revision/identity/read calls;
      zero `NTL_ApplyPatch` calls.
- [ ] Open it on an empty comp: no demo layers and zero writes.
- [ ] Open it on a comp containing only unmanaged layers: zero writes.
- [ ] Cancel AE's native New Composition dialog: the panel returns safely and
      remains read-only.
- [ ] Switch to a different comp: the old graph is retained read-only and is
      never written into the new comp.

**Gate:** opening, cancelling, switching, and reopening cannot mutate AE.

### B · One action is one command and one undo entry

- [ ] Create solid, null, and text layers from the toolbar and context menu.
- [ ] Rename, change label and blend mode, toggle visibility, reorder, and
      delete through the panel.
- [ ] Move a canvas node: layout changes and persists, but AE receives no patch.
- [ ] Drag an inspector number: the property follows and the whole drag is one
      undo entry.
- [ ] Undo and redo each host-writing action: graph and comp return to the same
      state without an extra reconciliation patch.

**Gate:** every visible edit has immediate panel feedback, the expected host
write, and exactly one correctly labelled undo entry per gesture.

### C · Relationships and effects

- [ ] Build layer → effect → effect entirely through the panel; effect order in
      AE matches the graph after undo and redo.
- [ ] Connect an expression node to a constant property; AE receives the tagged
      expression and the inspector marks the value driven.
- [ ] Parent one layer to another; the outliner remains a flat AE layer stack.
- [ ] Attempt a flow branch, a cycle, and a cross-type connection: all are
      refused before either model changes.
- [ ] Add an effect node: it shows effect identity and parameters, never a
      layer transform, and the next reconciliation pass is clean.

**Gate:** every drawn relationship exists in AE, invalid relationships are
atomic refusals, and no effect is re-added on an idle pass.

### D · AE-side drift and durable identity

- [ ] Nudge a constant in AE: the graph adopts it without a decision prompt.
- [ ] Nudge one while the graph holds an unwritten edit: both resolution buttons
      appear and each produces the state its label promises.
- [ ] Rename, hide, relabel, change blend mode, and reorder in AE: supported
      constants are captured and the next diff is empty.
- [ ] Duplicate a managed layer: the original retains its identity and the copy
      is never mistaken for it.
- [ ] Precompose a managed layer: its comment anchor rebinds the new native ID.
- [ ] Select a layer or effect node: AE selects the owning layer and Effect
      Controls follows when requested.

**Gate:** representable host edits converge; ambiguous identity blocks visibly;
no unmanaged layer is written or deselected.

### E · Persistence and project movement

- [ ] Save the small managed shot, close AE, reopen it, and load the panel: the
      graph is byte-equivalent and the diagnostic diff is empty.
- [ ] Verify layout, typed edges, parents, expressions, effect parameters,
      labels, visibility, blend modes, layer order, and text all survive.
- [ ] Save As to a second disposable path: subsequent graph saves follow the new
      project and do not overwrite an unrelated sidecar already there.
- [ ] Interrupt a sidecar replacement using the documented test hook or a
      prepared corrupt copy: the previous valid graph is recovered read-only.

**Gate:** reopen is lossless and non-destructive; project movement never writes
the graph beside the wrong project.

### F · M4.8–M4.12 regression pass

- [ ] A newly created layer exposes all five transforms; label and blend edits
      land in AE and the next pass is clean.
- [ ] Quit AE with the panel open: no modal-dialog script alert appears.
- [ ] The outliner composition checkbox hides/shows all layers in one undo entry
      and shows a mixed state when appropriate.
- [ ] Position scrub, arrow key, and step arrows agree; Shift is coarse and
      Ctrl is fine.
- [ ] Edit text, including two lines: the comp and card agree; changing a styled
      layer's string preserves typography.
- [ ] Keyframe Source Text: the field becomes read-only and reconciliation does
      not fight it.

**Gate:** every defect or behavior named by M4.8–M4.12 is seen working in the
real installed panel.

### G · Scale record

- [ ] Record read, clean diff, value patch, structural patch, and visible panel
      interaction timings for 50, 200, and 1,000 managed nodes.
- [ ] Record panel dimensions, CEP engine, hardware, minimap state, idle CPU,
      and whether any poll overlapped another operation.
- [ ] Calibrate the 200-node minimap threshold from the measurements rather than
      keeping it by assumption.

**Gate:** update `PERFORMANCE.md`; pointer interaction sustains 60 fps, visible
command feedback stays below 50 ms, and a clean 1,000-node diff stays below
16 ms in the panel runtime.
